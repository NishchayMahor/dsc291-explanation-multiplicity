# Open design choices (P3)
- **What counts as a sparse model's "explanation".** coef*x for L1 logistic (exact), decision-path feature set for trees. These are different objects from SHAP; compare rank/set metrics only.
- **Retrain source.** Bootstrap + seed (current, our retraining-test setup) vs members of a Rashomon set of XGBoost models. They answer different questions (training noise vs model choice); report both.
- **k for top-k Jaccard.** COMPAS has 7 raw features, so k = 2-3 is already coarse. Use Adult/FICO for k up to 5.
- **Zero attributions** are excluded from top-k sets (matters for sparse L1). Document this.
- **SHAP backend.** Falls back to XGBoost's `pred_contribs=True` when `shap` is missing. **VERIFIED 2026-11-17** (xgboost 3.4.1, shap 0.54.1, synthetic 7-feature data, depth 3 and depth 6 models): per-feature values are identical (max abs diff 0.0) and top-2 sets agree for 100% of rows. Reason, from the shap source (`explainers/_tree.py`): for XGBoost models with the default `feature_perturbation="tree_path_dependent"`, `shap.TreeExplainer` simply calls `booster.predict(pred_contribs=True)`. Caveats: (a) values are in log-odds (margin) units, not probability; (b) if you pass background data to TreeExplainer (interventional mode) the values change and will no longer match; (c) in this version pair `shap`'s `expected_value` (-0.008) did not equal XGBoost's bias column (which does make rows sum to the margin), so do not use `expected_value` with XGBoost 3.x without checking. The code drops the bias column, so (c) does not affect the metrics.
- **Novelty.** Hwang et al. 2026 (arXiv 2601.12654, NeurIPS 2026 E&D track) **read 2026-11-17**. It compares SHAP with SHAP across model seeds and background seeds (Kernel/Permutation SHAP; DT, RF, XGB, MLP, FT-Transformer). It has no sparse/interpretable model's own reasons, no bootstrap retraining, no exact TreeSHAP, and no conditioning on the decision staying the same. Our sparse-vs-SHAP comparison is still open. See RESEARCH.md.
- **Speed.** Pairwise metrics are O(R^2 x people). **VERIFIED:** defaults (20 retrains, 600 people, COMPAS) ran in about 21 s wall time on an M-series Mac (2026-11-17).
